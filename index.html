자료 범위

국내 공식 식품 자료가 중심이며, 일부 제품은 판매처의 표시정보를 별도로 연결했습니다. 수입제품도 일부 포함하지만 전 세계 제품을 모두 다루지는 않습니다.

항목 선택

일반 음식의 영양값은 특정 브랜드 제품의 값이 아닙니다. 식품명·업체·조리 상태·계산 기준을 확인하고 선택하세요.

미확인 값과 0

—는 확인된 값이 연결되지 않았다는 뜻입니다. 0은 자료에 0으로 기록된 값이며, 화면의 수치는 반올림될 수 있습니다.

먹는 양과 단위

100g 또는 100ml 기준에서 먹는 양에 맞춰 계산합니다. 원본 식품중량은 참고 정보이며 한 봉지·한 컵 분량으로 자동 계산하지 않습니다. g와 ml는 서로 환산하지 않습니다.

알레르기와 레시피 계산

알레르기 정보가 없다고 알레르기가 없는 것은 아닙니다. 레시피에서 검증된 영양정보가 없는 재료는 합계에 포함하지 않고, 이 경우 전체 값 대신 부분합계로 표시합니다.

      서비스 안내

      Food & Life는 국내 식품 자료를 중심으로 음식·제품·재료 검색과 섭취량별 영양 계산을 제공하는 베타 서비스입니다.

      식품별 출처와 계산 기준을 확인해 이용하세요. 정보는 순차적으로 보완되며 제품 변경이나 조리법에 따라 실제 값과 차이가 있을 수 있습니다.

      개인정보·입력정보 안내

      회원가입·결제 기능은 없습니다. 방문자 수와 이용 현황을 파악하기 위해 Google Analytics를 사용하며, 쿠키와 페이지 방문·기기·브라우저·유입 경로·이용 관련 정보가 Google에 전송될 수 있습니다. 광고 개인화와 Google 신호 기능은 사용하지 않습니다. 검색어·섭취량·레시피 수정값은 브라우저에서 처리하며, 앱에서 분석용 이벤트로 전송하지 않습니다.

      페이지와 식품 자료를 불러올 때는 호스팅 서비스인 GitHub Pages에 접속합니다. GitHub는 보안 목적으로 방문자의 IP 주소를 기록·보관합니다.

      외부 출처나 오류 제보 링크를 열면 해당 사이트의 개인정보 처리 기준이 적용됩니다.

      GitHub 개인정보 안내 ↗ Google 개인정보 안내 ↗
      문의·오류 제보

      검색이 안 되거나 영양값·계산·화면에 문제가 있으면 GitHub 제보 게시판으로 알려주세요. 식품명, 출처의 식품코드, 먹는 양과 단위, 기대한 결과와 실제 결과를 적으면 확인에 도움이 됩니다.

      GitHub 로그인이 필요하며, 등록한 글은 공개됩니다. 연락처·건강정보 등 개인정보는 적지 마세요. 링크를 누르는 것만으로 제보가 전송되지는 않습니다.
